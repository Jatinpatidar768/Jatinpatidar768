### 🚀 Featured Projects

---

#### 🤖 AI Document Intelligence Assistant (RAG)
[![Repo](https://img.shields.io/badge/GitHub-RAG%20Assistant-181717?style=for-the-badge&logo=github)](https://github.com/Jatinpatidar768)

A **RAG-based assistant** where users upload multiple documents and ask questions. Answers come with **source citations**, and the bot says "not found" instead of hallucinating.

- 🌟 **Key Features:**
  - Multi-document upload & chunking
  - Retrieval with **embeddings & vector search**
  - **Cited answers** + "not found" handling
  - Evaluation & experiments on retrieval quality
  - Built on a **zero / near-zero cost** stack

- 🛠 **Tech Stack:** Python · FastAPI · React.js · Embeddings · Vector Search · LLM

---

#### 🔌 SalesLens MCP (CRM MCP Server + AI Agent)
[![Repo](https://img.shields.io/badge/GitHub-SalesLens%20MCP-181717?style=for-the-badge&logo=github)](https://github.com/Jatinpatidar768)

A **read-only CRM MCP server** exposing tools over synthetic sales data, plus an **LLM agent loop** that answers typed questions by calling those tools.

- 🌟 **Key Features:**
  - **3 read-only MCP tools** built with FastMCP
  - Interactive **agent loop** (ask questions from the terminal)
  - Tested with **MCP Inspector** and **pytest**

- 🛠 **Tech Stack:** Python · FastMCP · MCP · Groq (LLM) · pytest

---

#### 🛒 Shopping24 (E-Commerce Platform, Deployed on AWS)
[![Repo](https://img.shields.io/badge/GitHub-Shopping24-181717?style=for-the-badge&logo=github)](https://github.com/jagmohan123/EcomerceFrontend)
[![Live](https://img.shields.io/badge/Live%20Demo-00C7B7?style=for-the-badge&logo=netlify&logoColor=white)](https://shoping24k.netlify.app/)

A complete **e-commerce web application** where users can browse products, add to cart, and place orders, with a **self-deployed AWS EC2 setup**.

- 🌟 **Key Features:**
  - Full **product catalog** with categories & search
  - **User authentication & profile management**
  - **Shopping cart & checkout**
  - **Admin dashboard** for product & order management
  - **Deployed end-to-end:** Nginx serves the React build, **PM2** runs the backend, MySQL on the same server

- 🛠 **Tech Stack:** React.js · Node.js · Express.js · MySQL · TailwindCSS · JWT Authentication · AWS EC2 · Nginx · PM2
